## 🚀 Key Features
- **100% Local & Private:** Protect your proprietary images locally without uploading them to external cloud servers.
- **Glossy & Frosted Glass Effects:** Lower watermark opacity (10–100%) and apply adjustable Gaussian blur so underlying image details remain visible through the logo.
- **Flexible Positioning & Scaling:** Choose between 5 placement anchors (Bottom-Right, Bottom-Left, Top-Right, Top-Left, Center) and set custom logo scale percentages.
- **Grayscale Conversion:** Convert full-color PNG logos into clean black-and-white overlays on the fly.
- **Smart Batch Resizing:** Automatically downscale oversized camera captures to a uniform pixel width (e.g., 1200px) to boost website page loading speeds.
- **Multi-Format Support:** Processes JPG, JPEG, PNG, and WebP files seamlessly.

## 📥 How to Download & Run
1. Go to the **[Releases](../../releases)** tab on the right side of this repository page.
2. Download the latest `watermarker.exe` file.
3. Launch `watermarker.exe` on your Windows PC.
4. Select your target image folder and your transparent PNG watermark.
5. Configure position, scale, opacity, blur, or resize settings, and click **Process Images & Add Watermark**.
6. Find your newly protected files inside the `watermarked_output` sub-folder!
